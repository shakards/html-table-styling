Professional HTML Tables

Learn how to create accessible, responsive, and beautifully styled HTML tables with modern CSS techniques.

Basic Table Structure

HTML tables are essential for displaying tabular data. A properly structured table includes semantic elements that improve accessibility:

Employee Information
Name Position Department Salary
Sarah Johnson Marketing Director Marketing $85,000
Michael Chen Senior Developer Engineering $110,000
Emily Wilson HR Manager Human Resources $92,000
Average Salary $95,667 
<!-- Semantic HTML Table Structure -->
<table>
  <caption>Employee Information</caption>
  <thead>
    <tr>
      <th scope="col">Name</th>
      <th scope="col">Position</th>
      <th scope="col">Department</th>
      <th scope="col">Salary</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Sarah Johnson</td>
      <td>Marketing Director</td>
      <td>Marketing</td>
      <td>$85,000</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="3">Average Salary</td>
      <td>$95,667</td>
    </tr>
  </tfoot>
</table>

Key Elements Explained

  • <caption>: Provides a title/description for screen readers
  • scope="col": Helps screen readers associate headers with cells
  • <tfoot>: For summary rows (appears at bottom regardless of position in HTML)

Responsive Table Techniques

Tables can be challenging on mobile devices. Here are professional responsive solutions:

Mobile-Friendly Employee Data
Employee Department Start Date Status
Robert Chen Engineering 2021-02-15 Active
Lisa Wong Design 2020-11-03 On Leave
David Kim Marketing 2022-01-10 Active 
<style>
  /* Base styles for all screens */
  table {
    width: 100%;
    border-collapse: collapse;
    margin: 1rem 0;
  }
  
  /* Mobile-specific styles */
  @media (max-width: 480px) {
    table {
      display: block;
    }
    
    thead {
      display: none;
    }
    
    tr {
      display: block;
      margin-bottom: 1rem;
      border: 1px solid #ddd;
    }
    
    td {
      display: block;
      text-align: right;
      padding-left: 50%;
      position: relative;
    }
    
    td::before {
      content: attr(data-label);
      position: absolute;
      left: 1rem;
      font-weight: bold;
      text-align: left;
    }
  }
</style>
